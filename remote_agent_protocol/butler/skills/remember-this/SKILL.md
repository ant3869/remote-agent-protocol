# Remembering

1. Keep only what will still be true next week: preferences ("I prefer Codex for UI
   work"), standing facts ("my repo is on the H drive"), and how they like things
   done. Not one-off requests or moods.
2. `remember` it with a short subject the user would search for ("agent
   preference", "email style") and the fact in one sentence, in their terms.
3. Confirm in a few words ("Noted, sir.").
4. Never store passwords, keys, tokens, or anything the user calls private.
5. If it contradicts something already remembered, `forget` the old one first.
